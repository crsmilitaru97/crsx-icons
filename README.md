# @crsx/icons

A lightweight icon set designed for modern web interfaces. It offers a range of clean, scalable SVG icons you can easily plug into your project.

## Installation
```bash
npm install @crsx/icons
```

## Usage

After installing, include the stylesheet in your page:

```html
<link rel="stylesheet" href="path/to/crsx-icons.css">
```

Use any icon by adding its class name:

```html
<i class="crsx-icon-name"></i>
```

Just replace `icon-name` with the one you need.
